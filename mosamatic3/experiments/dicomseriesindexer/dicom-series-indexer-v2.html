3. Export

One row per DICOM series; locator, topogram, scout and MPR cor images are excluded. Postcontrast delay uses the mean acquisition time across available slices and the recorded DICOM bolus start time. Missing timestamps yield a blank delay.

Requires a recent Chrome or Edge browser with directory access and persistent IndexedDB. Use the same browser/profile and page origin to resume; clearing site data also clears the saved index. For the most reliable storage, open this same file through localhost.
